# 7MATA Architecture

7MATA is a compliance-first mobility operating system.

Core primitives:

1. Actor
2. Intent
3. Capability
4. Action
5. Event
6. State
7. Evidence

Architectural principles:

- Domain-first
- Modular monolith first
- PostgreSQL as system of record
- Immutable financial ledger
- Durable outbox events
- Versioned regulatory profiles
- Deterministic compliance decisions
- Idempotent external operations
- Explicit state machines
- Tenant isolation
- Complete auditability
